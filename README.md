# finklham.at – Portfolio von Sebastian Stadlbauer

Zweisprachige (DE/EN) statische Portfolio-Seite. Astro, TypeScript, reines CSS. Läuft auf GitHub Pages unter `https://www.finklham.at`.

```bash
npm ci
npm run dev       # lokal entwickeln
npm run build     # nach dist/ bauen
npm test          # Tests (bauen die Seite und prüfen sie)
```

Deployment und DNS: siehe [docs/DEPLOY.md](docs/DEPLOY.md). Inhalte: `src/i18n` (Texte), `src/data` (Projekte, Kontakt, Impressum).
